# Audio Book Player 🎧

Este projeto é um **player de audiolivros** desenvolvido para prática de front-end e aprimoramento das habilidades com manipulação de áudio no navegador.  
A proposta é criar uma interface simples e funcional que permita **reproduzir, pausar e navegar entre faixas** de forma intuitiva.

## 🚀 Tecnologias Utilizadas
- HTML5  
- CSS3  
- JavaScript (API de Áudio)

## 🎯 Objetivos do Projeto
- Aprender a manipular áudio com JavaScript  
- Criar uma interface limpa e moderna  
- Explorar eventos do DOM para controle do player  
- Reforçar a prática de componentização e boas práticas de código

## 🧩 Estrutura de Pastas
```
/
├── index.html
├── /css
│   └── style.css
├── /js
│   └── script.js
└── /assets
    ├── audios/
    └── imagens/
```

## 💡 Como Executar o Projeto
1. Faça o download ou clone este repositório:  
   ```bash
   git clone https://github.com/seu-usuario/audio-book-player.git
   ```
2. Abra o arquivo `index.html` diretamente no navegador.

## 🧠 Aprendizados
Durante o desenvolvimento deste projeto, foi possível reforçar:
- Manipulação de elementos de áudio via JavaScript  
- Criação de controles personalizados (play, pause, próximo e anterior)  
- Organização e estilização moderna com CSS
